# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Email security reports to support@liquid.ai with:

- a description of the issue,
- steps to reproduce or affected files/components,
- any relevant logs or proof of concept,
- whether you believe sensitive data or credentials are exposed.

We will acknowledge receipt within 14 days and follow up with next steps after
initial triage.

## Supported Versions

Security fixes are provided for the current `main` branch and the latest public
release.

## Public Disclosure

Please give maintainers a reasonable opportunity to investigate and address the
issue before public disclosure.
